# IEEE_Invertiga-oMultiplosPontosPDE-PV
Código para matlab para a resolução do PDE-PV, na qual busca a minimização dos custos de geração de energia termoelétrica. Neste trabalho é proposta uma abordagem envolvendo métodos de otimização determinística e sistema dinâmico auxiliar para a determinação de múltiplos pontos de ótimos locais desse problema.
